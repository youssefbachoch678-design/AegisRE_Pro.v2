# AegisRE Pro — مشروع Android

تطبيق Android أولي لتحليل ملفات APK تحليلاً ساكناً، دون تثبيت الملفات المستهدفة أو تشغيلها.

## الوظائف الحالية
- اختيار ملفات APK عبر منتقي ملفات Android.
- حساب بصمة SHA-256.
- عدّ ملفات DEX والمكتبات الأصلية Native وملفات assets.
- حدود لحجم الملف والبيانات المفكوكة وعدد عناصر ZIP.
- واجهة داكنة مبنية باستخدام Kotlin وJetpack Compose.

## حدود الإصدار
هذا إصدار تأسيسي، وليس بديلاً عن JADX أو Ghidra. لا يفكك DEX إلى Java أو Smali، ولا يحلل كل تفاصيل Manifest الثنائي، ولا يعطي حكماً قاطعاً بأن الملف خبيث أو آمن.

## البناء
- Android Gradle Plugin 8.7.3
- Kotlin 2.0.21
- JDK 17
- Android SDK 35
- Minimum Android API 26

يمكن تشغيل workflow الموجود في `codemagic.yaml` لبناء APK تجريبي. لم يتم تأكيد نجاح بناء سحابي بعد؛ يجب مراجعة نتيجة Codemagic واختبار التطبيق على جهاز Android.

## الخصوصية والأمان
- لا توجد صلاحية INTERNET في Manifest.
- لا يتم تشغيل APK المختار.
- لا تُرفع الملفات المختارة تلقائياً.
- استخدم الملفات التي تملكها أو لديك إذن بتحليلها فقط.
- لا ترفع مفاتيح التوقيع أو كلمات المرور إلى المستودع.
