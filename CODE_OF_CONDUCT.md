# Code of Conduct

We want AegisRE Pro to be a respectful and welcoming project.

## Expected behavior

- Be respectful, patient, and constructive.
- Explain technical disagreements calmly.
- Give helpful feedback and accept feedback gracefully.
- Respect privacy. Do not publish personal information or private conversations.
- Keep discussions focused on improving the project.

## Unacceptable behavior

- Harassment, threats, insults, or discriminatory language.
- Spam, impersonation, or deliberate disruption.
- Sharing private information without permission.
- Pressuring contributors to add unsafe or unauthorized functionality.

## Project moderation

The project maintainer may edit, close, or remove contributions and discussions that violate this code of conduct. Serious or repeated violations may result in being blocked from participating.

For concerns, contact the repository maintainer through GitHub.
